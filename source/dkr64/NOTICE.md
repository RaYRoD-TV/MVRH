# Source provenance

The base is Golden Balloon commit
`106bad37244a2f8829bab21c655d25ff4b4dcdbf`. The files under `files/` contain
additions and modifications to that source; they are not a separate copy of
the complete upstream project.

Preserve the base project's
[LICENSE](https://github.com/akratch/goldenballoon/blob/106bad37244a2f8829bab21c655d25ff4b4dcdbf/LICENSE),
[NOTICE.md](https://github.com/akratch/goldenballoon/blob/106bad37244a2f8829bab21c655d25ff4b4dcdbf/NOTICE.md)
and [THIRD_PARTY.md](https://github.com/akratch/goldenballoon/blob/106bad37244a2f8829bab21c655d25ff4b4dcdbf/THIRD_PARTY.md).
Those notices distinguish the port's MIT code, the decompiled game source
and components with their own upstream terms. Existing copyright and license
notices in individual files remain intact.

The dependency manifest names OpenXR SDK 1.1.60 and SDL 2.32.10. The setup
command retrieves their selected files from the original source archives
without editing their contents. Their own notices accompany those files.

Game data and personal signing material are not part of this source package.
